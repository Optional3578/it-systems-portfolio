# IT & Systems Portfolio

A lightweight portfolio site summarising coursework and project work across 14 IT and engineering course collections. The pages are original summaries; no original course documents or project files are included.

## Run locally

No build step or package installation is required. From this folder, start any static file server, for example:

```sh
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and the `/ (root)` folder, then save.

GitHub Pages will provide the published site URL after its deployment completes. A live deployment is not implied by this repository’s contents.

## Public-content note

The site contains newly written course summaries and labels for the kinds of deliverables represented in the source folders. It intentionally excludes original assignments, lab documents, databases, presentations, project plans, Packet Tracer files, student IDs, and classmates’ names. Group attribution is used only when the source clearly identifies team work. Review each summary for accuracy before sharing.
